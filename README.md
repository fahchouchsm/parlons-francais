# Parlons Français

Lance l’entraîneur depuis un terminal :

```bash
python3 /home/simo/french_trainer.py
```

L’application fonctionne sans dépendance externe. Elle propose cinq temps (présent, passé composé, imparfait, futur simple et conditionnel présent), des fiches mémo, un quiz contextualisé et une banque de phrases de niveau B2.
